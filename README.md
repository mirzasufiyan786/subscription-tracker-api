# 📦 Subscription Tracker API

A fully functional Node.js REST API for tracking and managing subscriptions. This project focuses on user authentication, secure authorization, subscription operations, and error handling using modern backend practices.

---

## 🚀 Features

- 🔐 **User Authentication & Authorization** (JWT + Arcjet)
- 🔒 **Password Hashing** using bcrypt
- 📦 **CRUD APIs** for managing subscriptions
- 🔍 **Fetch Upcoming Renewals**
- 🧾 **User-based Subscription Retrieval**
- 🧱 **Built with** Node.js, Express, MongoDB, and Mongoose
- 🧰 **Centralized Error Handling** and Custom Middlewares
- 🧪 **Designed for Scalability and Security**
